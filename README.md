# OpenHC

**开源的 HiCar 车机端。** 装在安卓车机上，华为手机用数据线或无线投屏到车机屏幕。

[下载安装包](https://github.com/GGBondLab/OpenHC/releases/latest) · [更新记录](CHANGELOG.md) · [常见问题](#常见问题) · [报告问题](https://github.com/GGBondLab/OpenHC/issues) · [从源码构建](#构建)

> **只在比亚迪车机上开发和调试。** 作者只有一台比亚迪车机和一部纯血鸿蒙的华为手机，所有功能只在这套组合上测试过。
> 其他品牌的车机，或非纯血鸿蒙的手机上出的问题，作者没有设备，无法复现和修复；欢迎有能力的朋友自己调试，提交修复（见[参与](#参与)）。
>
> 车机是安卓 8.0 以下、或者手机不是纯血鸿蒙的，先看[常见问题](#常见问题)，那里列了别人维护的版本可以试。

## 适用范围

装在**车机**上，不是手机上。不需要 root、系统签名，不依赖车机自带的 HiCar，不用注册账号，不连任何服务器。
连接、投屏、声音、按键都不需要 ADB；只有「投屏时暂停车机搜 WiFi」「自动打开车机热点」这两个可选功能（默认关）用到车机本机的网络 ADB。
车机要允许安装 APK。

- **车机**：有线要安卓 6.0 起，无线要安卓 8.0 起。主线近期不再专门适配安卓 8.0 以下的车机（见[常见问题](#常见问题)第 1 条）。
- **手机**：带 HiCar 的华为或荣耀手机（作者只在纯血鸿蒙手机上测试过）。有线连接时，手机要关闭「USB 调试」。
- **无线方式**（设置 → 连接方式 → 无线方式）：
  - **车机开热点**（默认）：不用自己设置，连接时 OpenHC 自动让车机开热点给手机连；连接期间车机原来连着的 WiFi 会断开。
  - **车机自带热点**：实测最流畅：热点开着时车机不扫描 WiFi，热点选 5 GHz 也不和蓝牙挤在一起。
    要先在车机设置里打开车机自带的热点，再把热点名、密码和频段填进 OpenHC。限制：车机热点一段时间没有设备连着会自动关
    （比亚迪约 10 分钟），要用时重新打开；热点开着时车机自己连不了别的 WiFi；安卓 11 起的部分车机读不到热点的网卡地址，用不了这种方式。
    也可以打开「自动打开车机热点」（要车机打开网络 ADB）：连接时自动打开热点，连接结束后关掉，你自己打开的热点不会关。
    安卓 10 的车机实测可用，安卓 8、9 没测过，安卓 11 起不支持。
    车机有流量套餐时，手机连着车机热点可能会借车机的流量上网。
  - **5 GHz 直连**：车机建一个 WiFi 直连组让手机加入，优先用 5 GHz，车机原来连着的 WiFi 不用断开。要先打开车机 WiFi，有的车机不支持。

## 功能

- 画面：帧率自动跟随车机屏幕刷新率；清晰度三档可选；可全屏，也可保留车机底部导航栏。
- 触摸：多指操作，地图可以双指缩放。
- 声音：音乐和导航播报分开放；可以在设置里分别指定导航声道和音乐声道（编号同 DiPlay），带试听。
- 方向盘按键：上一首、下一首、播放 / 暂停。
- 免码回连：第一次输入车机上显示的连接码，之后不用再输。
- 自动连接手机：手机蓝牙连上车机、或打开 OpenHC（含开机自动打开）时，车机主动去连用无线连成功过的手机，不用扫码；手机热点关着时手机上不用点。
- 可选：插线时不再弹窗、开机自动打开、无线结束后恢复车机 WiFi。

## 使用

1. 车机安装 OpenHC（[下载](https://github.com/GGBondLab/OpenHC/releases/latest)）。装过自己编译的调试包的，先卸载再装，签名不同不能覆盖。
2. 第一次打开时，OpenHC 申请的权限（位置、附近设备、蓝牙等）都点允许。有的车机（多见于后装的安卓 6～9 车机）带系统自己的权限管家，会悄悄拦下这些申请：先到车机的权限管家（应用管家、权限管理之类）里给 OpenHC 打开位置、WiFi 状态等权限，再连接。
3. **有线**：打开 OpenHC，手机插车机 USB 口就会连接（没连上无线时插线优先），在手机上点「连接」，第一次输入车机显示的连接码。
4. **无线**：首页点「开始连接」，手机扫车机上的二维码。连成功过一次以后，上车手机蓝牙连上车机，OpenHC 就会自己连上手机（设置 → 启动 →「自动连接手机」，默认开）。

## 状态

有线、无线投屏和自动连接手机已在一台比亚迪安卓 10 车机和一部纯血鸿蒙的华为手机上验证。

已知限制（遇到问题见[常见问题](#常见问题)）：

- 用「车机开热点」方式时，连接期间车机自己的 WiFi 会断开；结束后安卓 10 起的车机可能要手动打开 WiFi（或打开「无线结束后恢复车机 WiFi」）。
- 手机开着热点时，自动连接要在手机上点一次（手机会问要不要关热点）。手机上设置过「连上车机就自动开热点」的，想上车免点连上，在手机上把它关掉。
- 通话和车机麦克风还没有验证。
- 安卓 10 起：OpenHC 在后台时，手机蓝牙连上车机要它自己弹出来、以及开机自动打开，都要先在设置 → 启动里打开悬浮窗权限；自己打开 OpenHC 再连则用不着。更新安装不会把它关掉。
- 比亚迪车机：「开机自动打开」「自动连接手机」要在设置 → 启动 →「打开比亚迪的后台启动设置」里把 OpenHC 的开关关掉；每次更新 OpenHC 后要再关一次。

## 常见问题

遇到问题先对照下面几类，找到和你一样的那一类。

**别人维护的版本**（OpenHC 作者没有测试过）

- [LinkeZhang/OpenHC](https://github.com/LinkeZhang/OpenHC/releases)：OpenHC 的分支。它的作者在鸿蒙 4.2 手机上实测过；另有安卓 4.1～9 车机专用版，在安卓 5.1 和 9 的车机上实测过。
  签名和 OpenHC 不同，装之前要先卸载 OpenHC。
- [hicar-android-receiver](https://github.com/huducat586/hicar-android-receiver)：另一个开源的车机端（它的作者在鸿蒙 4 的手机上测过，目前只做无线）。

**1. 车机是安卓 8.0 以下**

- OpenHC 主线近期不打算支持安卓 8.0 以下的车机。车型和安卓版本太多，各家车机的系统差别也很大，主线一个版本没法照顾到所有组合；
  每为一种老系统放宽一处，就可能把已经能用的车机改出问题，所以主线优先保证安卓 8.0 起的车机稳定。
- 安卓 6、7 的车机：有线目前还能用，但出了问题不再专门适配；无线用不了。
- 安卓 6.0 以下的车机：装不上 OpenHC。
- 这些车机可以试试上面 LinkeZhang 的安卓 4.1～9 车机版。

**2. 手机不是纯血鸿蒙（鸿蒙 3.x / 4.x、荣耀）**

- OpenHC 已经兼容了这些手机在投屏协商上的很多差别，鸿蒙 3.0 实测能用；鸿蒙 4.x、荣耀手机作者没有设备，没有实测过。
- 用最新版还是连不上或者没声音的，建议用上面 LinkeZhang 的版本。

**3. 扫码后手机提示「HiCar 连接失败，配对信息已被清除」**

- 这台手机用过车机自带的 HiCar 或同类应用的：先在手机 HiCar 里删掉旧的车机记录，再扫码。
- 还不行的话，可能是车机上自带的 HiCar 或「手机互联」占着同一个蓝牙服务，手机连到它那里去了。
  车机设置里如果有 HiCar 或「手机互联」的开关，先关掉再扫码试一次。

**4. 无线时画面卡、声音断断续续**

常见的原因有两种：

- **车机在扫描 WiFi**：比亚迪的语音助手、云听要定位时会扫一遍，那零点几秒画面和声音都会顿一下。「5 GHz 直连」方式最容易遇到；
  「车机开热点」时系统不会扫描。比亚迪车机也可以在小迪设置里关掉「地理位置服务」。
- **WiFi 和蓝牙挤在 2.4 GHz**：「车机开热点」的热点一般在 2.4 GHz，和蓝牙在同一个频段。靠手机蓝牙自动连上后的一段时间里（蓝牙正忙），
  以及手机在后台频繁定位时，画面可能比较卡；连上以后关掉手机蓝牙能缓解（车机的蓝牙电话会跟着断）。

最流畅的是「车机自带热点」（限制见[适用范围](#适用范围)）：热点开着时系统不扫描 WiFi，热点选 5 GHz 也不和蓝牙挤在一起。
用不了这种方式的车机，再在「车机开热点」和「5 GHz 直连」之间试，哪个顺用哪个。另外，无线时声音偶尔有很短的停顿，还在改进。

**5. 读不到车机的蓝牙地址**

- 手填的地址要和车机真实的蓝牙地址完全一致（可以用手机上的蓝牙扫描类应用查看），填错了手机找不到车机。
- 平板改的车机不在支持范围内。

**6. 蓝牙「开监听失败」（Error -1、-7 之类）**

- 车机系统直接拒绝了 OpenHC 开蓝牙服务，常见于后装车机：车机上可能有别的互联应用占着，或者车机的蓝牙不归安卓系统管。
  这种车机无线用不了，请用有线。

**7. 自动连接、开机自动连接失败**

- 车机去连手机时被手机拒绝了，原因还在查。这期间请扫码连接。

**8. 有线每次插线都要点授权**

- 打开设置里的「插线时不再弹窗」。

**9. 方向盘切歌没反应**

- 目前只在比亚迪车机上适配过。其他车机的按键作者没有设备，暂时没法适配。

## 报告问题

先看[常见问题](#常见问题)。还没解决的，请在 [Issues](https://github.com/GGBondLab/OpenHC/issues) 里写明：车机型号和安卓版本、
手机型号和系统版本、有线还是无线、操作步骤、期望和实际结果、出问题的时间，并附上诊断日志：出问题以后在 OpenHC
「设置 → 诊断 → 导出诊断日志」，把生成的文件附上（安卓 10 起在「下载/OpenHC」文件夹；更早的系统在
`Android/data/io.github.gcbond.openhc/files/OpenHC`）。
安全问题和连接参数的说明见 [安全说明](SECURITY.md)。

## 构建

需要 JDK 17 和 Android SDK 36：

```sh
./gradlew check assembleDebug
```

安装包在 `app/build/outputs/apk/debug/`。代码结构见 [架构说明](docs/ARCHITECTURE.md)。

要连得上手机，还需要一份连接参数文件 `openhc-identity.json`（不随源码发布，格式见 [示例](docs/identity.example.json)）：
把它单独放进一个目录，在 `local.properties` 里写 `openhc.identity.dir=<目录>`（或设环境变量 `OPENHC_IDENTITY_DIR`），构建时会打进安装包。

## 参与

自己动手解决了某个问题（例如让某款手机、某种车机能用了）的朋友，欢迎：

- **提 Pull Request**：审过后合并进来，所有车友都能用上；
- **或者在 Issue 里说一声**：写明改了什么、在什么车机和手机上实测过，附上你的分支或安装包链接，方便其他车友参考，作者也能照着修。

提 Pull Request 前请注意：

- 不要提交反编译得到的代码（Java、smali、伪代码）或照着它改写的代码，代码、注释和提交说明里也不要写厂商应用的类名、文件路径。
  注释里写协议本身的事实（字段、长度、字节序、时序和为什么这样做）就好。
- 测试数据一律用编造的值，不要用真实设备的地址、序列号、抓包或日志原文。
- `core` 下的模块是纯 Kotlin，不能用 `android.*`，要能在安卓 6.0 上运行（构建时会检查）。
- 提交前跑通 `./gradlew check assembleDebug`，并在说明里写清楚在什么车机、什么手机上实测过。用 AI 改的代码也一样。
- 提交的代码按本项目的 GPL-3.0 许可发布。
